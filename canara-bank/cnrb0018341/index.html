How the code CNRB0018341 is built

CNRB is the bank part: the letters of Canara Bank. The fifth character is always the digit 0. 018341 is the part that names this branch.

The MICR code 332015005 is the number printed along the bottom of this branch's cheques. 332 is the city (the same three digits that begin the PIN code 332404), 015 is the bank and 005 is the branch.

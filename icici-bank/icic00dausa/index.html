How the code ICIC00DAUSA is built

ICIC is the bank part: the letters of ICICI Bank. The fifth character is always the digit 0. 0DAUSA is the part that names this branch.

The MICR code 303828002 is the number printed along the bottom of this branch's cheques. 303 is the city (the same three digits that begin the PIN code 303303), 828 is the bank and 002 is the branch.

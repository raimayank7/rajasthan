How the code RBIS0JPPA01 is built

RBIS is the bank part: the letters of Reserve Bank of India. The fifth character is always the digit 0. JPPA01 is the part that names this branch.

What is the IFSC code of Reserve Bank of India, Public Accounts Dept?

The IFSC code is RBIS0JPPA01. Use it with the account number to send money by NEFT, RTGS or IMPS to an account held at this branch.

What is the MICR code of Reserve Bank of India, Public Accounts Dept?

The list gives no MICR code for this branch. Look at the bottom line of a cheque of the branch: the 9-digit number there is the MICR code.

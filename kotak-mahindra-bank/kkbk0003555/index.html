How the code KKBK0003555 is built

KKBK is the bank part: the letters of Kotak Mahindra Bank. The fifth character is always the digit 0. 003555 is the part that names this branch.

The MICR code 302485021 is the number printed along the bottom of this branch's cheques. 302 is the city (the same three digits that begin the PIN code 302012), 485 is the bank and 021 is the branch.

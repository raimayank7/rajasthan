How the code BARB0BHADES is built

BARB is the bank part: the letters of Bank of Baroda. The fifth character is always the digit 0. BHADES is the part that names this branch.

The MICR code 312012540 is the number printed along the bottom of this branch's cheques. 312 is the city (the same three digits that begin the PIN code 312602), 012 is the bank and 540 is the branch.
